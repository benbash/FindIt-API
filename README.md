# FindIt API

FindIt API is a Node.js, Express, and MongoDB backend for reporting lost items, reporting found items, searching through item records, and managing item claims.

## Stack

- Node.js
- Express
- MongoDB with Mongoose
- JWT authentication

## Setup

1. Install dependencies:

```bash
npm install
```

2. Create `.env` from `.env.example` and set:

```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/findit-api
JWT_SECRET=replace-with-a-strong-secret
NODE_ENV=development
```

3. Start the server:

```bash
npm run dev
```

## Assigned module endpoints

### Lost items

- `GET /api/lost-items`
- `GET /api/lost-items/:id`
- `POST /api/lost-items`
- `PATCH /api/lost-items/:id`
- `DELETE /api/lost-items/:id`

### Found items

- `GET /api/found-items`
- `POST /api/found-items`
- `PATCH /api/found-items/:id`
- `DELETE /api/found-items/:id`

### Search

- `GET /api/items/search`

Supported query parameters:

- `type=lost|found|all`
- `category=...`
- `location=...`
- `status=...`
- `keyword=...`
- `fromDate=2026-07-01`
- `toDate=2026-07-31`
- `page=1`
- `limit=20`

### Claims

- `POST /api/claims`
- `GET /api/claims`
- `PATCH /api/claims/:id`

## Example request bodies

### Report lost item

```json
{
  "title": "Black Backpack",
  "description": "Contains a laptop and notebooks",
  "category": "Bag",
  "location": {
    "description": "Near the school library",
    "city": "Lagos",
    "state": "Lagos",
    "country": "Nigeria",
    "landmark": "Main gate"
  },
  "dateLost": "2026-07-30T10:00:00.000Z",
  "contactPhone": "+2348012345678",
  "tags": ["black", "laptop"],
  "images": ["https://example.com/bag.jpg"],
  "rewardAmount": 5000
}
```

### Report found item

```json
{
  "title": "Silver iPhone",
  "description": "Phone found on a bus seat",
  "category": "Phone",
  "location": {
    "description": "BRT terminal",
    "city": "Lagos",
    "state": "Lagos",
    "country": "Nigeria",
    "landmark": "Waiting area"
  },
  "dateFound": "2026-07-31T14:30:00.000Z",
  "contactPhone": "+2348098765432",
  "storageLocation": "Terminal office",
  "tags": ["iphone", "silver"]
}
```

### Create claim

```json
{
  "foundItem": "PUT_FOUND_ITEM_ID_HERE",
  "reason": "It is my phone and I can describe the wallpaper and passcode hint",
  "proofDetails": "The lockscreen has my child photo",
  "supportingImages": ["https://example.com/receipt.jpg"]
}
```
